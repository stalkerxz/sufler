Ваш голос задаёт темп

  1. Подготовьте текст. Вставьте сценарий слева или загрузите файл .txt в кодировке UTF-8.
  2. Выберите режим. «По голосу» следует за произнесёнными словами. «По скорости» двигает текст с выбранным темпом.
  3. Начните чтение. В голосовом режиме разрешите микрофон. Делайте паузы — текст подождёт.
  4. Вернитесь к нужной фразе. Нажмите на слово, чтобы читать с него. Если пропустили большой фрагмент, также выберите новую точку кликом.
Для голосового режима рекомендуем Chrome. Этот HTML можно открыть напрямую. Если браузер запрещает микрофон из файла, запустите «Запустить локально.command» из комплекта и откройте локальный адрес. Поддержка зависит от браузера и сервиса распознавания. Звук может передаваться сервису браузера; приложение не записывает и не хранит аудио. При недоступном сервисе выберите «По скорости».
