# Суфлёр

Браузерный телесуфлёр для записи видео и лекций. Текст следует за произнесёнными словами или прокручивается с заданной скоростью.

**[Открыть суфлёр в браузере](https://stalkerxz.github.io/sufler/)** · **[Скачать локальный комплект](https://github.com/stalkerxz/sufler/releases/latest)**

- Вставьте сценарий или загрузите файл TXT в UTF-8.
- В меню «Вид» можно настроить размер текста, ширину, интервал и положение строки чтения от 10% до 80%. Для чтения рядом с камерой попробуйте 15–20%.
- Доступны зеркальный и полноэкранный режимы. Текст и настройки сохраняются в браузере.

## Запуск

| Вариант | Как запустить |
| --- | --- |
| В браузере | Откройте GitHub Pages, вставьте текст и нажмите «Начать чтение». Режим «По скорости» доступен сразу. Режим «По голосу» использует Web Speech API браузера. Его доступность зависит от браузера, микрофона и сервиса распознавания. [Документация Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition) |
| Локально на macOS | Скачайте `sufler-local.zip` из релиза, распакуйте и запустите `Запустить локально.command`. Нужен Python 3. При первом запуске потребуется интернет для установки Vosk. После подготовки русская речь распознаётся на устройстве. |
| Один HTML-файл | Скачайте `sufler.html` из релиза и откройте его в браузере. Редактор и прокрутка по скорости работают офлайн. |

В локальном режиме для русского языка браузер передаёт звук процессу Vosk на `127.0.0.1`. Аудио обрабатывается в памяти. В браузерном режиме звук может обрабатывать сервис распознавания браузера.

## Управление

Пробел — старт, пауза или отмена отсчёта; ↑/↓ — переход по строкам; T — перезаписать абзац; R — в начало; F — полный экран; Esc — отменить отсчёт и выйти из режима съёмки. Нажмите на слово, чтобы начать с него. Выбранная высота строки сохраняется между запусками.

## Разработка

`src/` содержит интерфейс, прокрутку и сопоставление речи, `scripts/` — сборку и запуск локального сервера, `tests/` — модульные тесты. Для сборки нужен Node.js 22 или новее.

```sh
npm test
npm run build
```

Откройте `dist/index.html`. Команда `npm run build:pages` обновляет `docs/index.html`, из которого GitHub Pages публикует сайт.

Для локального распознавания используйте готовый комплект из релиза. Его модель `vosk-model-small-ru-0.22` распространяется на условиях Apache 2.0. Текст лицензии приложен к архиву. [Модели Vosk](https://alphacephei.com/vosk/models)

## Новое в 1.4.0

- **Следование за речью:** сопоставление написанных цифрами целых чисел 0–999999 с русскими словами и сокращений США, РФ, МВД, МГУ, ПК, ИИ, ООО, кг, км. Для сокращений используются названия букв, для кг/км — «килограмм»/«километр». Даты, дроби и произвольные сокращения лучше писать словами. Во время молчания позиция текста не меняется; повторная фраза не откатывает курсор. Для повтора есть отдельная кнопка дубля.
- **Дубли:** переход к соседним абзацам и «Перезаписать абзац» с отсчётом 0, 3, 5 или 10 секунд. Повторное нажатие старт/пауза отменяет отсчёт.
- **Съёмка:** скрывает настройки и заголовок, оставляет текст и компактные кнопки паузы/выхода. Это режим интерфейса, видеозапись он не ведёт.
- **Область чтения:** перетаскивание стрелки мышью/пальцем, управление стрелками клавиатуры после фокуса, ширина от 240 px, варианты «У камеры», «По центру» и сохранение своего варианта.
- **Ремарки:** `[пауза]`, `[улыбнуться]` и другие пометки в квадратных скобках видны в тексте, но не входят в счётчик слов и сопоставление речи.
- **Библиотека:** поиск, папки, копирование, корзина, до 100 сценариев и 12 предыдущих версий каждого. Версии сохраняются раз в 30 секунд редактирования; перед вставкой, вырезанием и крупной заменой дополнительно сохраняется текущий текст. Есть выгрузка и восстановление JSON-копии. Восстановление копии заменяет библиотеку и предлагает браузеру скачать прежнюю. Убедитесь, что загрузка разрешена. Данные хранятся только в этом браузере и не синхронизируются между сайтом и localhost.
- **Проверка звука:** выбор входа, индикатор уровня и отдельная проверка распознавания. Выбор входа применяется к проверке микрофона и локальному Vosk; Web Speech использует системный вход. Звуковой тест идёт 10 секунд, речевой — до 12 секунд. Проверка не перемещает текст. Доступ к микрофону зависит от разрешений и защищённого контекста: [getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia), [SpeechRecognition.start](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/start).
- **Пульт:** старт, пауза, повтор дубля, соседние абзацы, темп ±5 слов/мин. Работает через локальный комплект, без внешнего сервера.

### Подключить телефон

1. Запустите новый локальный комплект и подключите компьютер и телефон к одной доверенной Wi-Fi сети.
2. В настройках откройте «Пульт с телефона» → «Включить пульт».
3. Скопируйте показанную ссылку и откройте её на телефоне. Если показаны несколько адресов, выберите доступный в вашей сети. При запросе ОС разрешите локальные входящие подключения Python. Гостевые сети с изоляцией устройств могут блокировать связь.
4. Оставьте вкладку суфлёра видимой на компьютере. На телефоне появятся кнопки управления. Темп влияет только на режим «По скорости».
5. После записи нажмите «Отключить». Ссылка также истекает через 2 часа. Закрытие локального сервера отключает пульт.

Пульт открывает отдельный HTTP-порт в локальной сети только после включения. Ссылка содержит случайный ключ доступа; любой, кому она известна, может управлять чтением. Не публикуйте её. Текст сценария и аудио на этот порт не передаются. Телефону доступны только команды и состояние чтения. На GitHub Pages и в отдельном HTML без локального сервера пульт недоступен.

### Проверки для разработчика

```sh
npm ci
npm test
npm run test:remote
npm run build
npm run build:pages
```

Для проверки интерфейса запустите `npm start` в отдельном терминале, затем:

```sh
npx playwright install chromium
npm run test:browser
```

`SUFLER_TEST_URL` задаёт адрес тестового локального сервера (по умолчанию `http://127.0.0.1:8765/`). `SUFLER_BROWSER_CHANNEL=chrome` использует установленный Chrome. `SUFLER_TEST_REMOTE=1` дополнительно проверяет пульт в отдельном браузерном контексте; нужна доступная локальная сеть. Тесты используют изолированное хранилище браузера и не меняют пользовательские сценарии. Python-проверки тестируют авторизацию пульта, срок сессии, отбрасывание устаревших команд и отключение.

Для 1.4.0 также проверен полный путь Chrome → аудиозапись русского текста → локальный Vosk → движение курсора, завершение захвата при паузе и отдельный речевой тест. Живой микрофон пользователя, физический телефон, Safari и Firefox требуют проверки на соответствующих устройствах.
